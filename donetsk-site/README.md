# Донецк — учебный многостраничный сайт

Статический проект на HTML5 и CSS, выполненный без конструктора сайтов.

## Страницы

- `index.html` — описание Донецка, фотогалерея из шести снимков и ближайшие события октября 2026 года.
- `history.html` — хронологическая таблица из 16 дат и пояснения.
- `infrastructure.html` — географическое положение, карта OpenStreetMap, районы и транспорт.
- `culture.html` — театры, музеи, культурные деятели и афиша.
- `feedback.html` — демонстрационная форма с HTML5-валидацией.
- `about.html` — биография автора, уровни языков и навыков.
- `style.css` — адаптивная общая таблица стилей.

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер в этой папке:

```bash
python3 -m http.server 8000
```

Затем перейдите по адресу `http://localhost:8000`.

## Примечания

- Афиши проверены 9 октября 2026 года; сведения о расписании могут меняться. Перед посещением сверяйте их с первоисточником.
- В форме обратной связи используется `mailto:` с демонстрационным адресом. Это не серверная отправка и не хранение данных.
- Внешние ресурсы (Google Fonts, OpenStreetMap iframe, сайты театров) требуют доступа в интернет.
- Источники исторических фактов и афиш перечислены непосредственно на страницах.
